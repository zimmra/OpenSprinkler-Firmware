# Keyestudio KS0212 relay HAT

Opt-in support for the Pi 3 / KS0212, using BCM GPIO 4, 22, 6, 26
for standard stations 1-4, active HIGH. No wiring changes are required.
The default build is unchanged. Scheduling and the API are unchanged.
Stations 5 and above have no physical outputs; disable them. Do not configure
these four stations as special GPIO, remote, or bundle stations.

## Build on the Pi

Initialize dependencies with the upstream installer without enabling a service:

```bash
sudo bash build.sh -s ospi
make clean
make VERSION=OSPI EXTRA_CXXFLAGS=-DOSPI_KS0212
```

The first command builds standard OSPi temporarily; do not run that binary on
this HAT. Stop any existing OpenSprinkler service before building. Never run
the stock build or upstream updater on the HAT: GPIO 4/22 would be driven as
shift-register clock/latch. After each upstream update, clean and rebuild
with the flag above. The existing upstream service can launch the resulting
binary; the build flag is not a runtime argument.

## Migration and checks

Back up Home Assistant and existing controller settings. With valve power
isolated, remove the remote_rpi_gpio platform from HA and restart HA, then
stop/disable pigpiod on the Pi so it cannot also drive these pins. Disable
1-wire on GPIO 4 if enabled. Configure four standard stations in OpenSprinkler,
disable stations 5-8 and expansion boards, and initially disable weather
adjustment. Store the recurring schedule in OpenSprinkler.

Verify all four relays are off at controller startup, each station operates
only its corresponding relay, and a short timed run stops with networking
disconnected. Test service restart and reboot before restoring normal valve
power. Connect Home Assistant through its OpenSprinkler integration and use
timed runs rather than HA-delayed off commands.

This handles HA/network loss while the local controller is running. It does
not guarantee shutoff during a Pi/process crash, GPIO ownership failure, or
welded relay. Offline scheduling after a power cycle also requires valid
system time (consider an RTC).

## Software regression test

```bash
g++ -std=gnu++14 -DOSPI -DOSPI_KS0212 -I. -include cstdint \
  tests/ks0212_test.cpp -o /tmp/ks0212-test
/tmp/ks0212-test
```

This mocks GPIO calls and checks all 256 station masks with the controller
both enabled and disabled. It does not substitute for testing the real HAT.
